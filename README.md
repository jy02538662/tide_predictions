## 门 1：观察者依赖引力修正（已收口 = 负结果）

### 推导链（每步标注「据」或「新推导」）

| 步 | 内容 | 性质 |
| --- | --- | --- |
| 1 | 无外部观察者 ⟹ 尺度不变 ⟹ 观察者态 ρ=C/λ（对数均匀谱，无特征尺度） | 据（预印本 1.3 §3，唯一性定理） |
| 2 | 真实观察者谱**有限支撑** λ∈[λ_min, λ_c]（观察者有分辨率上限） | 新假设 |
| 3 | 截断引入特征尺度 Δ=ln(λ_c/λ_min)，破坏尺度不变 | 新推导 |
| 4 | h(ω)~log\|ω\| 的支撑被截到 \|ω\|≤Δ ⟹ G(t) 的 1/t 尾巴被修正 | 新推导 |
| 5 | 硬截断 → 振荡 (logΔ)sin(Δt)/t；平滑截断 → 指数尾巴 | 新推导 |
| 6 | 光锥 r=t ⟹ V(r)=1/r 修正，特征尺度 r~Δ=ln(λ_c/λ_min) | 新推导 |

### 物理问题（一句话）

预印本 1.3 证的是「**全知**观察者（ρ=C/λ 无截断）→ 纯 1/r」。但真实观察者**有限**（有 λ_c 分辨率上限）。这个截断会破坏尺度不变，产生一个**观察者依赖的引力修正**，特征尺度由观察者的「分辨率范围」Δ=ln(λ_c/λ_min) 决定。门 1 就是要把这个修正的形式 + 量级算出来。

### 实验清单

| 实验 | 类型 | 问题 | 结果 |
| --- | --- | --- | --- |
| `exp_scale_invariance` | 符号 | 尺度不变 ρ(cλ)=c⁻¹ρ(λ) 的唯一解 = C/λ；截断如何破坏它 | 见 `_last_run.json` |
| `exp_observer_g` | 符号+数值 | 有限观察者 h(ω)=log\|ω\| 截断 → G(t) 尾巴修正 | 见 `_last_run.json` |
| `exp_cutoff_robust` | 数值 | 硬截断 vs 平滑截断，修正是否 robust | 见 `_last_run.json` |
| `exp_gravity_correction` | 数值 | 光锥 r=t → V(r) 修正形式 + 量级 + 可测性 | 见 `_last_run.json` |

### 运行

```bash
py -m experiments.exp_scale_invariance
py -m experiments.exp_observer_g
py -m experiments.exp_cutoff_robust
py -m experiments.exp_gravity_correction
```

### 门 1 最终结论（负结果）

**观察者内化不产生可观测的「观察者依赖长程引力修正」。**

- 尺度不变唯一解 ρ=C/λ（据，符号确认）；
- 截断引入特征尺度 Δ=ln(λ_c/λ_min)（新推导，符号确认）；
- 但**硬截断的振荡项 (logΔ)sin(Δt)/t 是截断伪影**，物理的平滑窗口下尾巴严格恢复 1/t（数值确认）；
- **G_Δ(t) 随 Δ→∞ 严格收敛到 −π/t（纯 1/t）**（scipy quad 确认）。

根因：观察者分辨率 λ_c 只影响短程（大频率），不影响长程（ω→0 的对数奇性）。长程 1/r 是引力可观测的部分，故门 1 不产生可测的观察者依赖修正。

## 门 2：内禀 Kramers 材料对称性预言（已收口 = 正结果，独有预言成立）

### 门 2 最终结论（正结果）

**spinless（无自旋）系统物理时间反演 T²=+1 本无 Kramers，但 π 磁通涌现 T'=JK（T'²=−1）强加 Kramers 简并——标准理论里不可能，框架独有。**

- T'=JK 保护 Kramers ⟺ J·H*·J⁻¹=H ⟺ JM=−MJ（虚扰动 iM，M 实反对称）；
- M 与 J 反对易 → Kramers 存活；M 与 J 对易 → Kramers 破坏（数值两极坐实）；
- 物理 Haldane 次近邻虚跃迁（真实破 T 扰动）→ Kramers 仍存活（**t₂=0.1~5.0 全存活，门 2 扩展 `exp_gate2_extension` 已推到 5.0**）。

可检验材料预言：真实材料若实现 π 磁通（受挫磁体 / 冷原子 π 磁通晶格 / 拓扑材料），应表现 spinless 系统的 Kramers 二重简并，且对破 T 扰动鲁棒。

## Born 偏离判据（已精确化）

### 推导链（据，预印本 1.0 §4/§6）

| 步 | 内容 | 性质 |
| --- | --- | --- |
| 1 | 自指（无外部观察者）⟹ 概率 SO(3) 协变 ⟹ p=f(m̂·n̂)（弱命题，定理 1） | 据 |
| 2 | 逆命题：p 依赖绝对方向 ⟺ 存在外部参考系（偏离判据，定理 2） | 据 |
| 3 | 偏离度 D = (Σ_{ℓ≥1, m≠0} \|c_{ℓm}\|²)^{1/2}（球谐展开，只统计方位角分量） | 精确化 |

### 精确化结果（exp_born_precision）

- **纯 Born**：D ≈ 0.03（数值噪声，随采样点 N 增大 →0），无外部观察者；
- **引入偏好方向 ε**：D ≈ 2.04·ε（线性，ε=0.1 时 D≈0.2，远大于噪声）——外部观察者的定量签名。

**关键澄清**：偏离度 D 只统计 **m≠0** 的球谐分量（Y_{ℓm} 含 e^{imφ}，m≠0 才对应「方位角依赖」= 横向偏好 = 外部参考系）。m=0 的 Y_{ℓ0} 是轴对称的（只依赖极角 cosθ），不违反 SO(3) 协变。

**诚实边界**：主打「偏离 ⟺ 外部观察者」判据，不推导 Born 本身（(1+x)/2 是输入，arXiv:2604.27125 已抢 Born 推导）。
